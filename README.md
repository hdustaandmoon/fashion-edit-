# Fashion Edit｜电商趋势词观察

每天查看服饰趋势关键词的变化，为选品、上新、商品标题和营销内容寻找参考。

**[打开趋势词看板 →](https://hdustaandmoon.github.io/fashion-edit-/)**

适合面向墨西哥市场的服饰商家、选品人员和电商运营使用。日常查看只需打开网页，无需安装软件或保持电脑开机。

## 每天怎么用

1. **先看更新时间**：确认页面显示的最近成功采集日期，判断数据是否及时。
2. **查看红色 NEW 词**：勾选“只看新增”，优先了解新出现的关键词。
3. **筛选与你相关的词**：输入商品词或分类名称，查看冬季服饰、节日商品、潮流风格等方向。
4. **结合店铺情况做判断**：核对目标客群、现有库存、供货周期和利润，再决定是否测试商品或调整内容。

建议把关键词作为待验证的线索，结合自己店铺的搜索、点击、转化和成交表现评估效果。

## 可以用于哪些工作

| 工作场景 | 使用方法 |
| --- | --- |
| 选品与上新 | 从相关分类中寻找款式、季节和使用场景线索，加入候选选品清单。 |
| 商品标题优化 | 挑选与商品实际属性一致的西语表达，自然融入标题和描述，避免堆砌无关词。 |
| 活动策划 | 关注 Buen Fin、圣诞等节日关键词，结合备货和物流时间安排活动。 |
| 短视频与直播 | 围绕相关穿搭、保暖需求或节日场景设计内容，再用实际互动和成交验证。 |
| 团队复盘 | 查看历史快照，记录关键词变化和对应运营动作，便于后续比较。 |

例如，看到 `ropa de invierno mujer`，可以检查店铺是否有适合的女士冬季服饰，再评估标题表达和内容主题。涉及品牌、人物或 IP 的词，需要先确认商品真实性及使用授权。

## 黄色重点词与商家选品建议

黄色“重点”保留来源页面的重点标记，与红色 NEW 独立判断；一个词可以同时是重点词和新增词。

商家选品建议随每日采集同步，保留来源的标题和内容。来源未修改时建议保持不变，不会自动编造新建议。搜索或只看新增时，选品建议仍会显示。

## 红色 NEW 代表什么

**红色 NEW 表示：与上一成功采集日期相比，当前新增或重新出现的关键词。**

- 第一次采集用于建立基线，不会把所有词标为新增。
- 同一天重复更新，仍与上一采集日期比较，当日新增标记会保留。
- 下一个采集日期如果没有变化，这些词就不再标红。
- 首次收录日期是本工具第一次记录到该词的日期，不代表该词开始流行的日期。
- 同一个词可能属于多个分类，因此会在不同分类中出现；顶部总数按去重后的词统计。

**NEW 不代表搜索量上涨、销量增长或新品爆发。** 来源没有提供搜索量、增长率和销量排名，本工具也不计算这些指标。

## 更新时间与数据来源

- **计划更新时间**：每天北京时间上午 **09:15**，实际执行可能延迟。
- **数据来源**：[Fashion Edit 站内热搜趋势词](https://fashion-edit-merchant.netlify.app/#trending)。
- **更新方式**：自动检查来源页面，记录关键词并发布更新后的看板。
- **历史保存**：每天保留最新一次成功采集结果，可通过页面底部“历史快照”查看。

来源页面提供的是整理后的趋势关键词，只有来源发生变化，本工具才会发现变化。每日检查成功，不代表每天一定会出现新词。

## 页面功能

- **搜索趋势词**：按关键词或分类文字查找，西语原词可以直接复制使用。
- **只看新增**：集中查看本次标红的关键词。
- **首次收录日期**：了解本工具何时首次记录该词。
- **本次移出的词**：查看相对上一采集日期已从来源列表中消失的词。
- **下载 Excel**：一键下载 `.xlsx` 文件，包含“趋势词”和“选品建议”两个工作表。趋势词包含分类、重点标记、新增标记、首次收录日期、采集日期及来源。重点词标黄，新增词用红字显示。同词多个分类分别列行；导出全部当前数据，不受网页筛选影响。
- **历史快照**：保留每日 JSON 记录，供进一步核对。旧快照没有记录重点词或建议时，不回填未经确认的历史内容。

## 常见问题

### 今天为什么没有新增？

可能是来源没有更新，也可能是新增词与已收录词重复。先查看最近成功采集时间；日期正常且没有 NEW，通常表示本次没有发现新增词。

### 更新时间停留在前几天怎么办？

联系维护人员检查仓库的 **Actions → Daily trends and Pages**。抓取或部署失败时，网页会保留上次成功发布的结果。请以页面显示的成功检查时间为准。

### 被移出的词是不是不能再用了？

不一定。移出只说明该词不在本次来源列表中，不能据此判断没有需求。是否继续使用，应结合店铺实际表现。

### 可以直接据此大量备货吗？

建议先验证需求、成本和供货条件，再决定采购规模。关键词列表不能保证需求、利润或库存周转。

## 给维护人员

### 飞书群每日通知

在飞书群添加自定义机器人后，将 Webhook 保存到仓库 **Settings → Secrets and variables → Actions → New repository secret**，名称为 `FEISHU_WEBHOOK_URL`。不要把地址写进代码或公开文件。

更新程序后，定时任务和手动运行任务会在网页部署成功后推送飞书摘要，包括趋势词数量、新增词、来源重点词、商家选品建议、看板及 Excel 下载链接。无新增也会推送当天摘要；普通文件提交只更新网站，不推送群消息。手动重复运行会再次发送。

如果机器人启用了关键词校验，可将允许的关键词设为 `Fashion Edit`；启用签名校验时，还需将签名密钥保存为仓库 Secret `FEISHU_SIGN_SECRET`。如果启用了 IP 白名单，请确认执行任务的网络可以访问机器人。

首次验证：上传 `notify_feishu.py`、新版 `.github/workflows/daily.yml` 和测试文件后，在 **Actions → Daily trends and Pages → Run workflow** 手动运行，检查群消息和 `Notify Feishu` 步骤。没有配置 Webhook 时跳过通知；发送失败会将通知步骤标红，但已经部署的网站仍可使用。网络超时不自动重发，请先检查群内是否收到，避免重复消息。

消息较长时，只列出前 15 个新增词、前 15 个重点词和前 8 条建议，其余内容通过看板或 Excel 查看。Excel 以下载链接提供，不是飞书附件。

[飞书自定义机器人官方说明](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)

### 网站维护

日常使用者直接访问看板即可。维护人员可在仓库 **Actions → Daily trends and Pages → Run workflow** 手动触发更新；部署来源应设为 **Settings → Pages → GitHub Actions**。

项目文件：

| 路径 | 用途 |
| --- | --- |
| `requirements.txt` | Excel 导出依赖 |
| `notify_feishu.py` | 部署成功后发送飞书趋势摘要 |
| `tracker.py` | 抓取关键词、比较变化并生成网页 |
| `docs/` | 发布到 GitHub Pages 的看板 |
| `docs/data/` | 当前数据和每日历史快照 |
| `.github/workflows/daily.yml` | 每日自动采集和部署任务 |

本地维护需要 Python 3.11 或以上版本，先安装 Excel 导出依赖：

```powershell
python -m pip install -r requirements.txt
python tracker.py
python -m http.server 8000 --directory docs
```

随后打开 http://localhost:8000 查看页面。修改采集逻辑后，可运行：

```powershell
python -m unittest discover -s tests -v
```
